## 💻 Sobre o Projeto

O **Java Streaming** é uma aplicação desktop desenvolvida em Java com arquitetura MVC e persistência em PostgreSQL. O projeto simula uma plataforma de streaming, permitindo autenticação de usuários, busca dinâmica de conteúdos e interações individuais através de likes e dislikes.

O sistema foi estruturado utilizando conceitos avançados de Programação Orientada a Objetos, modelagem UML e separação em camadas (Model, View, Controller e DAO).

# 💡 Aprendizados e Desafios

Durante o desenvolvimento, os principais desafios superados foram:

- Estruturar corretamente a arquitetura MVC separando responsabilidades entre View, Controller, DAO e Model.
- Implementar persistência relacional utilizando PostgreSQL e consultas SQL.
- Desenvolver sistema de reações inspirado em plataformas reais como YouTube.
